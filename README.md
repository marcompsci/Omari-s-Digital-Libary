# Omari's Digital Library

A personal, Goodreads-style bookshelf website. Books face the reader spine-out on a shelf, stand up like dominoes as you scroll, and pull off the shelf into a detail view with descriptions, quotes, and summaries.

## Features

- Typewriter title on the home page
- Scroll-driven domino shelf that overlaps the header and settles onto the ledge
- Book detail view with a 3D pull-out cover, quotes, and expandable panels (Why This Matters, Brief Summary, Brief Investment Strategies)
- Swipe, arrow keys, or Previous/Next to move between books
- Genre filters, search, and a hamburger menu with genre counts
- "My Catalogue" page, sortable by title, author, or year
- "Recommend a book" page with a floating recommendations shelf on page 1
- Light and dark themes, reduced-motion support

## Files

- `index.html` — the whole site in one file (HTML, CSS, and JavaScript)
- `bookmark-buddyy-xcode-prompt.md` — the prompt for building the iOS version, "Bookmark Buddyy"

## Running it

Open `index.html` in a browser, or serve the folder with any static host (for example GitHub Pages).

Shared recommendations are saved through the claude.ai artifact data store, so they only work on the claude.ai-hosted version of the page. Anywhere else the site works fully, and the recommendation form explains that it can't save from that view.
